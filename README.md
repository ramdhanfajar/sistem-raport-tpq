
#  Sistem Raport TPQ

Aplikasi berbasis web untuk mengelola data santri, pengajar, nilai, dan administrasi TPQ.

##  Fitur Utama
- Login multi-role (Admin, Pengajar, Santri)
- Manajemen data santri & pengajar
- Input & laporan nilai
- Export laporan (PDF)
- Keamanan session & role-based access

##  Teknologi
- PHP Native
- MySQL
- HTML, CSS, JavaScript
- Bootstrap
